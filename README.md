# Projects

Welcome to my personal practice repository! Here are all of the small projects I made while learning to understand C++ and other development tools more deeply.

Each folder contains a self-contained mini-project with its own source code and documentation.

## Repository Contents

| Project | Description | Focus Areas |
| :--- | :--- | :--- |
| **[`bubble_sort`](./bubble_sort)** | Implementation and visualization of the Bubble Sort algorithm. | Sorting algorithms, array manipulation, visual presentation |
| **[`snake`](./snake)** | Console-based Snake game featuring grid management and randomized item spawning. | Object-oriented programming (classes/structs), `std::vector`, 2D arrays |
| **[`tictactoe`](./tictactoe)** | Classic console Tic-Tac-Toe game. | Game loops, win-condition logic, user input handling |

## Goals & Learning Focus

* **C++ Fundamentals:** Strengthening knowledge of memory management, standard library containers (`std::vector`), object-oriented design, and control flow.
* **Algorithms & Logic:** Translating classic games and sorting algorithms into clean, structured code.
* **Developer Workflow:** Practicing version control with Git and GitHub, organizing multi-project repositories, and writing clear project documentation.
